# RdpSwitch

Миниатюрный переключатель RDP для Windows: плавающая панель поверх окон, одна строка с названиями открытых подключений и кнопка сворачивания всех RDP справа.

## Возможности

- Только открытые окна стандартного клиента Windows `mstsc.exe`.
- Переключение одним нажатием, восстановление свёрнутого окна.
- Названия без IP; полный заголовок доступен при наведении. Если в заголовке только адрес, отображается «Сеанс N».
- Порядок при переключении сохраняется, новые подключения добавляются справа.
- Перемещение всей панели за любое название с сохранением положения.
- Кнопка монитора справа сворачивает только RDP. Другие приложения остаются на месте, подключения не закрываются.
- Закрытые подключения остаются серыми на своих местах и сохраняются между запусками. Обычный клик ничего не делает; правый клик → «Подключиться» сразу запускает повторное подключение по сохранённому адресу.
- Иконка в трее и меню выхода. Панель скрывается, если нет ни открытых, ни сохранённых подключений.
- Настройки из меню трея: можно отключить сворачивание остальных RDP при выборе подключения на панели. По умолчанию включено; выбор сохраняется между запусками.

## Запуск

Требуются Windows x64 и .NET Desktop Runtime 10. Для сборки нужен .NET SDK 10 с поддержкой Windows Desktop.

```powershell
dotnet build -c Release
.\bin\Release\net10.0-windows\RdpSwitch.exe
```

Установка и права администратора для обычного запуска не требуются. Повторный запуск не создаёт вторую панель.

Для сборки отдельной папки с приложением и встроенным .NET:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o publish
.\publish\RdpSwitch.exe
```

## Управление

| Действие | Результат |
| --- | --- |
| Нажать название | Переключиться на RDP |
| Правый клик по открытому подключению → «Свернуть» | Свернуть только выбранный RDP |
| Правый клик по закрытой плитке → «Подключиться» | Сразу подключиться по сохранённому адресу |
| Зажать название и потянуть | Переместить всю панель |
| Нажать монитор справа | Свернуть все RDP из панели |
| Навести на название | Посмотреть полный заголовок |
| Правый клик по панели → «Выход» | Завершить приложение |
| Правый клик по иконке в трее → «Вернуть панель» | Вернуть панель в исходное положение |
| Правый клик по иконке в трее → «Настройки» | Настроить сворачивание остальных RDP |

Положение хранится в `%LOCALAPPDATA%\RdpSwitch\position.json`.
Настройки хранятся в `%LOCALAPPDATA%\RdpSwitch\settings.json`.

Названия и адреса запомненных подключений хранятся в `%LOCALAPPDATA%\RdpSwitch\connections.json`. Пароли не сохраняются. Для повторного подключения запускается `mstsc.exe /v:адрес`; специальные настройки исходного `.rdp`-файла не восстанавливаются. Адрес берётся из заголовка окна.

## Ограничения

Поддерживается стандартный клиент `mstsc.exe`; Windows App и сторонние RDP-клиенты не поддерживаются. Окно потерявшего связь подключения остаётся в списке до закрытия. Имена берутся из заголовков окон, поэтому утилита не определяет имя сервера по IP.

Отображение поверх полноэкранного RDP и перевод фокуса зависят от поведения Windows и клиента; эти сценарии требуют проверки на конкретной системе.
