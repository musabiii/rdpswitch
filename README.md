# RdpSwitch

Плавающая панель Windows: одна строка с названиями открытых подключений стандартного клиента mstsc. Нажатие переключает окно, перетаскивание за название перемещает панель. Положение сохраняется. Правый клик → «Выход». В трее есть возврат панели в исходное положение.

Если подключений нет, панель скрывается и остаётся в трее. Окно потерявшего связь подключения остаётся в списке до закрытия. Windows App и сторонние RDP-клиенты не поддерживаются.

Сборка: `dotnet build -c Release`. Запуск: `bin/Release/net10.0-windows/RdpSwitch.exe`. Нужен .NET Desktop Runtime 10 x64. Полноэкранные подключения и ограничения фокуса Windows требуют проверки на конкретной системе.
